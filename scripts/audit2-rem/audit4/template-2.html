Method notes for future auditors. (1) Chrome’s innerText applies CSS text-transform: the holdout label renders as “HOLDOUT — ANSWER NOT IN PROMPT”, so case-sensitive string checks fail even though the card is visible. (2) A programmatic element.click() does not move focus, so focus-restore checks must use a real mouse click or an explicit focus. (3) Guarded action failures (e.g., zero-recipient RFQ dispatch) intentionally log a client console error from the thrown Convex action; the UI converts it into a visible error toast.
